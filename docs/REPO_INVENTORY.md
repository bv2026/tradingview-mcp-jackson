# Repository Inventory

Last reviewed: 2026-07-18

## Purpose

This repo is the TradingView MCP bridge for controlling a live TradingView Desktop instance through CDP. The active codebase is split between the MCP server, CLI entrypoint, core TradingView operations, and a set of workflow scripts and generated reports.

## Top-Level Layout

| Path | Purpose | Status |
|---|---|---|
| `src/` | MCP server, CLI entrypoint, and core TradingView tool implementations | Active |
| `config/` | Screener mappings, strategy JSON, and screener notes | Active |
| `scripts/` | Workflow helpers for watchlists, weekly review, archive rotation, and launch/debug utilities | Active, with legacy cleanup completed on 2026-07-18 |
| `reports/` | Daily and weekly generated briefs, summaries, and data bundles | Active output |
| `CSV/` | Input exports for watchlist and screener generation | Active input |
| `docs/` | Human-facing setup and workflow documentation | Active |
| `tests/` | Sanity checks | Active |
| `node_modules/` | Installed dependencies | Generated |
| `.claude/` | Claude-specific task/skill helpers and settings | Active workflow support |

## Active Scripts

| Script | Role |
|---|---|
| `scripts/archive-old-reports.mjs` | Zips and moves old report weeks into `reports/archive/` |
| `scripts/build-momentum-watchlists.mjs` | Rebuilds `config/strategy-sp_ndx.json` and `config/strategy-r2k.json` from weekly CSV exports |
| `scripts/build-watchlist-configs.mjs` | Rebuilds thematic and ARK watchlist configs from static CSV exports |
| `scripts/build-weekly-review.mjs` | Produces the weekly review data bundle from saved daily reports and session JSON |
| `scripts/ct_tv_data.py` | Combines CT data with TradingView futures brief data for the decision pipeline |
| `scripts/launch_tv_debug.bat` | Windows TradingView launcher helper |
| `scripts/sync-tool-count.mjs` | Updates docs with the current MCP tool count |
